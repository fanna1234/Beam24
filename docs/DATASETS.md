# Dataset Provenance and Access

Datasets are external and are never committed to this repository.

| Dataset | Purpose | Public source | Integrity | License/boundary |
|---|---|---|---|---|
| Synthetic ideal ULA | Full angular/K quality sweep | Generated by `quality_oracle_greedy_dither.py` | Deterministic source hash and seed | Repository MIT code; generated values |
| Acoular 64-channel scene | Small non-ULA multi-source pilot | Zenodo record 5809069 | `three_sources.h5` MD5 `ca8efe2834a63dda373ee67ce6b0678f`; `array_64.xml` MD5 `42fa95ba46ddd940548e66e41b1737a4` | Follow the Zenodo record license and attribution |
| LOCATA development set | Real spherical-array negative boundary | Zenodo record 3630471 | `dev.zip` MD5 `d5a5417c3f6b2ed0e43581dd06f504e6` | Open Data Commons Attribution; do not redistribute in the artifact |
| SPIB/SACLANT VLA | Real regular-line-array spectrum validation | `https://spib.linse.ufsc.br/array.html` | `A2601_1_10.zip` MD5 `b05df6154890cc4fc64c044cc61a9f2c` | Public research data; acknowledge SACLANT Centre; do not claim a repository-owned license |

`artifact/scripts/get_data.sh` downloads only public files with recorded URLs
and verifies their checksums. A reviewer can also set `BEAM24_DATA_ROOT` to an
existing dataset tree.
